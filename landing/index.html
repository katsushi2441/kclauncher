SYNC

Sync with Thunderbird, iPhone, Android & Google Calendar

The launcher's calendar (kcaldav) speaks CalDAV. Read and write the same events from any device — the server is the single source of truth, so everything stays in sync.

💻PC / Thunderbird

Two-way sync via the built-in CalDAV client. Events you add on your phone show up on your PC.

📱iPhone / iPad

Just add a CalDAV account to the built-in Calendar app. No app to install.

🟢Android / Google Calendar

With DAVx5 (below), your events appear in the Android system calendar — the Google Calendar app — to view and edit.

🟢 Sync with the Google Calendar app on Android (DAVx5)

Install DAVx5 (free)

The F-Droid build is free. Open DAVx5 on F-Droid and install. (The Google Play build is paid.)

Add your account

In DAVx5, tap + → “Login with URL and user name”. Enter your kcaldav URL, user name and password.

See it in Google Calendar

Once synced, enable the kcaldav calendar in the Google Calendar app. View, add and edit events — and they sync back to Thunderbird / iPhone.

Events are stored on your own kcaldav server, not in Google's cloud (DAVx5 syncs your device with the server).

Want to run it against your own server? The launcher's calendar opens Kurage's CalDAV server kcaldav. Put kcaldav.php on your own server and add that URL as a tile to use it as your personal calendar.
